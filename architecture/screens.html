Navigation behavior

The app uses React state (activeView), rather than a URL router. Patient and plan selections are held separately. The HTML guide has its own document links and browser history.

All roles receive the base navigation; Corrections is added for counselors, and API Testing Harness, Users, Forensic Logs, and Settings are added for administrators. Account is a separate shell action. Navigation visibility does not grant API permission.
