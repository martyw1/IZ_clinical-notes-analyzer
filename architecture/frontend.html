R3 Recovery Services / Application architecture

Frontend structure

React and TypeScript screens served as built Vite assets.

Composition

  1. frontend/src/main.tsx mounts React StrictMode and loads app.css.
  2. frontend/src/App.tsx selects the V2 app.
  3. frontend/src/v2/AppV2.tsx owns authentication, active view, patient selection, and treatment-plan selection.
  4. frontend/src/v2/components/AppShell.tsx renders navigation, Account, sign-out, content, and version footer.
  5. Page components compose clinical panels and API clients.

Request and identity contracts

  • frontend/src/v2/api/request.ts
  • frontend/src/v2/api/json.ts
  • frontend/src/v2/api/identity.ts
  • frontend/src/v2/api/treatmentPlanMapper.ts
  • frontend/src/v2/api/patientRecordMapper.ts
  • frontend/src/v2/hooks/useRequestGeneration.ts

The request session guards against stale results after sign-out or session changes. Patient / plan identity includes record, source, and version selectors to avoid ambiguous selection.
