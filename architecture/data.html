Plan version → clinical evidence → evaluation / checklist evidence

This is a conceptual relationship map, not a complete database schema. Migration source is the schema authority.

Deterministic evaluation

Rule packages and the canonical 42-step checklist drive evaluation. Incomplete or conflicting evidence must preserve Missing Data, Needs Review, Conflicting Evidence, and Unable to Evaluate outcomes; compliance must not be guessed. Optional LLM behavior must remain disabled by default and is not required for clinical decisions.
