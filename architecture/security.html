Access & boundaries

Role checks, patient scope, privacy protection, and open owner gates.

Roles and scope

RoleScope / navigation notes
AdministratorAdmin tools are added to navigation. Patient access remains facility-scoped.

Privacy controls

  • Uploads remain encrypted at rest using the existing storage envelope.
  • Saved API configuration is encrypted; browser output exposes configured-state flags rather than secrets.
  • Audit events and error responses must not expose note text, original upload filenames, PHI, or connection secrets.
  • Examples and fixtures must be synthetic. This guide extracts source structure only and reads no runtime data.

Production boundaries

Alleva sync is off by default and remains gated by explicit live read-only authorization, credentials, mapping and vendor requirements, bounded pagination/rate limits, attachment behavior, and compliance approval. The available implementation and mapping documentation do not prove a production tenant run.

LOC-change policy, full Windows platform validation, and owner-controlled production qualification remain open. Historical package test counts qualify their exact artifacts only.
