# Evidence Coverage Map

The V2 evidence coverage map shows:

- Criteria total.
- Criteria with evidence.
- Criteria missing evidence.
- Criteria with conflicts.
- Content sections present.
- Content sections missing.
- Unmapped runtime fields.
- Unused content fields.
- Swagger-only fields.
- Runtime-only fields.
- Warnings.

Managers use this panel to understand which treatment-plan content supported each checklist criterion and which available content remains unmapped.
