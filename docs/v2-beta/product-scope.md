# V2 Product Scope

V2 Beta focuses on treatment-plan evidence management for local Windows desktop use:

- Status Dashboard with manual upload, API readiness, and Alleva sync readiness cards.
- Treatment Plans Workbench as the primary screen.
- Manual Upload contract for point-in-time evidence.
- API Testing Harness with Alleva patient-centered pulls and large all-fields jobs.
- Full treatment-plan detail viewer for authorized manager/admin review.
- 42-step checklist evidence and manager actions.
- Forensic logs with safe summaries only.
- Role-based user management surface.
- Settings that keep the LOC-change blocker visible and configurable.

Patient names are excluded by default. Compliance decisions remain deterministic and do not require an LLM.
