# V1 to V2 Gap Matrix

Date: 2026-07-09

Purpose: recovery planning for the active `codex/v2-beta-local-rebuild` V2 beta. This matrix was produced before product code changes. It compares the active V2 runtime against the archived V1 runtime under `deprecated/v1/` and treats a capability as complete only when backend, frontend, persistence, validation, security, and tests prove it.

Important: live Alleva credentials were provided out-of-band for testing, but credentials are not copied into this document and must not be committed, logged, exported, or shown in browser payloads.

Checkpoint update: after the initial matrix was written, V2 gained a protected normalized treatment-plan aggregate JSON import path backed by encrypted local SQLite persistence and frontend Manual Upload wiring. V2 also gained protected UTF-8 text, Markdown, CSV, TSV, PDF, and XLSX manual treatment-plan parsing into the same encrypted aggregate/checklist path, plus encrypted original source-file archival for those uploads without storing original filenames. Archived manual source files now appear as safe metadata in Treatment Plan detail and can be downloaded or deleted by manager/admin users through role-gated, audited, path-safe routes that use generated filenames and preserve the normalized aggregate. A mismatched file Patient ID and override now requires explicit manager confirmation; the corrected aggregate retains a safe warning and the audit trail excludes the detected source ID. Durable manager-action storage for approve/comment/return/override actions is in place, with persisted reviews merged into Treatment Plan detail and shown in the UI after reload/restart. The manager return and counselor submission workflow now has dynamic queue state and role-aware controls, but assignment/routing and a manager re-review queue remain open. Checklist evidence CSV export and API harness artifact downloads now have bounded, tested safety checks. Live Alleva sync remains an open gap.
