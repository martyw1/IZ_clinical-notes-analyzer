# Clinical staff desktop

Wallpaper: `R3-Clinical-Staff-Apps-Wallpaper.png`. Created October 12, 2026 from the owner-supplied R3 developer wallpaper reference, keeping its green branding and open left side for shortcuts. Text: **R3 Clinical Staff Apps — Less friction. More focus on care.**

To apply to the intended Windows account: open Windows Settings > Personalization > Background, choose Picture and select this PNG. Use Fill. Creating this asset does not alter another Windows account.

Recreate the source-checkout desktop tools using `scripts/create-source-desktop-shortcuts.ps1` as the intended Windows user. Account credentials are supplied privately and excluded from source control. See the current HTML guide for the complete tool list, backup/restore limitations and support instructions.
