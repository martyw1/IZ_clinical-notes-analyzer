## Coverage targets
- Unit/API tests for auth, health, role checks.
- Integration tests for workflow transitions and audit logging.
- E2E smoke test for login + dashboard rendering.

## Defect template
- ID
- Severity
- Steps to reproduce
- Expected vs actual
- Root cause
- Fix reference commit
